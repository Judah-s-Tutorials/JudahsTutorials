Digression: Switch Expressions

We're going to start employing switch expressions. For those not familiar with this topic, the following is a brief discussion.

Standardized in Java 14, Switch Expressions offer an alternative to the traditional switch statement. They employ a lambda-like syntax that eliminates break statements. This discussion assumes familiarity with the traditional switch statement. Here are some additional references:

Traditional switch statements:

  • Java Switch, from W3Schools
  • Java Switch Statement, from Baeldung

Switch Expressions:

  • Switch Expressions, from the Oracle Java Language Updates

■ Cases use arrows, and don't fall through:

Traditional Form:

switch ( input )
{
case "January":
    System.out.println( "1/Jan" );
    break;
case "February":
    System.out.println( "2/Feb" );
    break;
default:
    System.out.println( "eh?" );
}

Expression Form

switch ( input )
{
    case "January" -> System.out.println( "1/Jan" );
    case "February" -> System.out.println( "2/Feb" );
    default -> System.out.println( "eh?" );
}

■ Stack cases using commas:

Traditional Form:

switch ( input )
{
case "January":
case "February":
case "March":
    System.out.println( "Q1" );
    break;
case "April":
case "May":
case "June":
    System.out.println( "Q2" );
    break;
default:
    System.out.println( "eh?" );
}

Expression Form

switch ( input )
{
    case "January", "February", "March" -> 
        System.out.println( "Q1" );
    case "April", "May", "June" -> 
        System.out.println( "Q2" );
    default -> System.out.println( "eh?" );
}

■ Switch expressions have values:

Traditional Form:

String result = "";
switch ( input )
{
case "January":
    result = "1/Jan";
    break;
case "February":
    result = "2/Feb";
    break;
default:
    result = "eh?";
}
System.out.println( result );

Expression Form:

String result2 = 
    switch ( input )
    {
        case "January" -> "1/Jan";
        case "February" -> "2/Feb";
        default -> "eh?";
    };
System.out.println( result2 );

■ The case expression can be a block; use yield to establish the value of the case:

Traditional Form:

Point2D point   = null;
switch ( property )
{
case "Polar":
    double  rad = 5 * theta + 1;
    Polar   pol = Polar.ofRTheta( rad, theta );
    point = pol.toPoint();
    break;
case "Param":
    double  xco = 5 * Math.cos( theta );
    double  yco = 2 * Math.sin( theta );
    point = new Point2D.Double( xco, yco );
    break;
default:
    point = new Point2D.Double( 0, 0 );
}
System.out.println( point );

Expression Form

point = 
    switch ( property )
    {
        case "Polar" -> {
            double  rad = 5 * theta + 1;
            Polar   pol = Polar.ofRTheta( rad, theta );
            point = pol.toPoint();
            yield point;
        }
        case "Param" -> {
            double  xco = 5 * Math.cos( theta );
            double  yco = 2 * Math.sin( theta );
            point = new Point2D.Double( xco, yco );
            yield point;
        }
        default -> {
            System.err.println( "unsupported" );
            yield new Point2D.Double( 0, 0 );
        }
    };
System.out.println( point );
