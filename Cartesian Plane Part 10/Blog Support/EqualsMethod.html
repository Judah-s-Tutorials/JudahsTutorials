Important note: This page is about the Java equals(Object), and we're going to stick to that. But we can't mention equals without referring to the equals and hashCode contract. This states that if you override equals (or hashCode) you must also override hashCode (or equals).

Java equals Method

The equals method is declared in the Object class. Functionally, it's not very robust. It looks like this: 

public boolean equals( Object object )
{
    if ( this == object )
	    return true;
	else
	    return false;
}

In other words, Object.equals(Object) judges two objects to be equals if they are the same object. This is not typically very helpful. For example, I can have two different string objects, and if they both have the value "cat" we would normally consider them equals, even if Object.equals(Object) does not.
