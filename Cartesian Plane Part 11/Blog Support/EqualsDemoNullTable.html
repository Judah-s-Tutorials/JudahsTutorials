Important note: This page is about the Java equals(Object), and we're going to stick to that. But we can't mention equals without referring to the equals and hashCode contract. This states that if you override either equals or hashCode, you must override the other as well.

Java equals Method

The equals method is declared in the Object class. Functionally, it's not very robust. It looks like this: 

public boolean equals( Object object )
{
    if ( this == object )
	    return true;
	else
	    return false;
}

In other words, Object.equals(Object) judges two objects to be equal if they are the same object. This is not typically very helpful. For example, I can have two different string objects, and if they both have the value "cat" we would normally consider them equals, even if Object.equals(Object) does not.

Consider the following class: 

public class EqualsDemo1
{
    private final String    alpha;
    private final String    beta;
    
    public EqualsDemo1( String alpha, String beta )
    {
        this.alpha = alpha;
        this.beta = beta;
    }
	...
}

In the above example, let's say that we would like an EqualsDemo1 object to be equal to another object if:

  1. It is non-null;
  2. It is type EqualsDemo1;
  3. Their respective alpha fields are equal; and
  4. Their respective beta fields are equal.

Of course, now we need to ask what does it mean for the alpha and/or beta fields to be equal? The easiest thing is to ask if: this.alpha.equals(otherObject.alpha). Unless this.alpha is null, in which case it's equal to otherObject.alpha only if otherObject.alpha is also null.

The equals Contract

When overriding equals you must make sure that your implementation meets the following requirements.

  1. Your implementation must be reflexive; it must be true that obj.equals(obj).
  2. Your implementation must be symmetric; if obj1.equals(obj2) is true, obj2.equals(obj1) must be true; if obj1.equals(obj2) is false, obj2.equals(obj1) must be false.
  3. Your implementation must be transitive; if obj1.equals(obj2) is true, and obj2.equals(obj3) is true, then obj1.equals(obj3) must be true.
  4. Your implementation must be consistent; the result of obj1.equals(obj2) must be the same every time you invoke it (assuming no information used in equals comparisons is modified).
  5. Your implementation must handle null; the result of obj1.equals(null) must always be false.

public class EqualsDemo1
{
    ...
    @Override
    public int hashCode()
    {
        return Objects.hash(alpha, beta);
    }

    @Override
    public boolean equals( Object other )
    {
        boolean result  = false;
        if ( this == other  )
            result = true;
        else if (other == null)
            result = false;
        else if ( !(other instanceof EqualsDemo1) )
            result = false;
        else
        {
            EqualsDemo1  that   = (EqualsDemo1)other ;
            if ( this.alpha != null && !this.alpha.equals( that.alpha ) )
                result = false;
            else if ( this.alpha == null  && that.alpha != null )
                result = false;
            else if ( this.beta != null && !this.beta.equals( that.beta ) )
                result = false;
            else if ( this.beta == null && that.beta != null )
                result = false;
            else
                result = true;
        }
        return result;
    }    
}

Some notes about the above code:

  • Lines 4-8: Since we're overriding equals we must also override hashCode.
  • Lines 14-15: Testing to see if this and other are the same object is not strictly necessary; it's an optimization.
  • Lines 16-19: The other object isn't equal to this if it's null, or if it's the wrong class.
  • Lines 23-24: if this.alpha isn't null, we can ask if this.alpha.equals( that.alpha ).
  • Lines 25-26: if this.alpha is null, we can ask if that.alpha is also null.
  • Lines 27-30: go through all the null checking and .equals checking again for the beta field.

One more remark about the equals method itself. You may have noticed that lines 23 through 30 in the above example are rather painful. And for a class that has a lot more than two fields it will get very tedious. Note also, however, that the pattern is going to be the same when testing any pair of non-primitive values. public class EqualsDemo2
{
    private final String    alpha;
    private final String    beta;
    // ...
    @Override
    public boolean equals( Object other )
    {
        boolean result  = false;
        if ( this == other  )
            result = true;
        else if (other == null)
            result = false;
        else if ( !(other instanceof EqualsDemo2) )
            result = false;
        else
        {
            EqualsDemo2  that    = (EqualsDemo2)other ;
            if ( !Objects.equals( this.alpha, that.alpha ) )

                result = false;

                result = true;

JUnit Test for equals

The test for an equals method is tedious. Let's write a test for the equals method in EqualsDemo1.

I will start by declaring two different values for each field in the class: 

@Test
void testEquals()
{
    String      alpha1  = "alpha 1";
    String      alpha2  = "alpha 2";
    String      beta1   = "beta 1";
    String      beta2   = "beta 2";
    // ...
}

Now declare two objects. Their initial values should be equal. 

@Test
void testEquals()
{
    // ...
    EqualsDemo1 objA    = new EqualsDemo1( alpha1, beta1 );
    EqualsDemo1 objB    = new EqualsDemo1( alpha1, beta1 );
    // ...
}

Test one object against itself and verify that the result is true; test the object against an object of a different class and verify that the result is false; test the object against null and verify that the result is false; 

@Test
void testEquals()
{
    // ...
    assertEquals( objA, objA );
    assertNotEquals( objA, new Object() );
    assertNotEquals( objA, null );
    // ...
}

Verify that the two objects are equal, and that their hashcodes are equal; verify symmetry by reversing the order of the test. 

@Test
void testEquals()
{
    // ...
    assertEquals( objA, objB );
    assertEquals( objB, objA );
    assertEquals( objA.hashCode(), objB.hashCode() );
    // ...
}

Configure the objects as shown (the only difference is that objB.alpha is null), and verify that they are not equal:

@Test
void testEquals()
{
    String      alpha1  = "alpha 1";
    String      alpha2  = "alpha 2";
    String      beta1   = "beta 1";
    String      beta2   = "beta 2";
    EqualsDemo1 objA    = new EqualsDemo1( alpha1, beta1 );
    EqualsDemo1 objB    = new EqualsDemo1( alpha1, beta1 );
    
    assertEquals( objA, objA );
    assertNotEquals( objA, new Object() );
    assertNotEquals( objA, null );
    assertEquals( objA, objB );
    assertEquals( objB, objA );
    assertEquals( objA.hashCode(), objB.hashCode() );
    
    // field alpha
    
    objA = new EqualsDemo1( alpha1, beta1 );
    objB = new EqualsDemo1( null, beta1 );
    assertNotEquals( objA, objB );
    assertNotEquals( objB, objA );
    
    objB = new EqualsDemo1( alpha2, beta1 );
    assertNotEquals( objA, objB );
    assertNotEquals( objB, objA );
    
    objA = new EqualsDemo1( null, beta1 );
    objB = new EqualsDemo1( alpha1, beta1 );
    assertNotEquals( objA, objB );
    assertNotEquals( objB, objA );
    
    objA = new EqualsDemo1( null, beta1 );
    objB = new EqualsDemo1( null, beta1 );
    assertEquals( objA, objB );
    assertEquals( objB, objA );
    assertEquals( objA.hashCode(), objB.hashCode() );
    
    // field beta
    
    objA = new EqualsDemo1( alpha1, beta1 );
    objB = new EqualsDemo1( alpha1, null );
    assertNotEquals( objA, objB );
    assertNotEquals( objB, objA );
    
    objB = new EqualsDemo1( alpha1, beta2 );
    assertNotEquals( objA, objB );
    assertNotEquals( objB, objA );
    
    objA = new EqualsDemo1( alpha1, null );
    objB = new EqualsDemo1( alpha1, beta2 );
    assertNotEquals( objA, objB );
    assertNotEquals( objB, objA );
    
    objA = new EqualsDemo1( alpha1, null );
    objB = new EqualsDemo1( alpha1, null );
    assertEquals( objA, objB );
    assertEquals( objB, objA );
    assertEquals( objA.hashCode(), objB.hashCode() );

    objA = new EqualsDemo1( null, null );
    objB = new EqualsDemo1( null, null );
    assertEquals( objA, objB );
    assertEquals( objB, objA );
    assertEquals( objA.hashCode(), objB.hashCode() );
}
